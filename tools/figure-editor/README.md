# Figure editor

Stub (the Scribe writes the documentation). Plan: `proposals/figure-editor.md`.

**Inputs**
- `symbol-pack/`: a pinned copy of `circuit-model/symbols/`. Only
  `scripts/copy-symbol-pack.js` writes it, and `MANIFEST.json` and `VERSION` record the
  source tag and commit. Never edit it by hand.
- Saved figures: circuit-schema `circuit/0.2` JSON.

**Outputs**
- Saved figures (`.json`, canonical: the same figure always gives the same bytes).
- SVG export: real size in cm, with no external references.

**API**
- `mount(element, { pack, open })` from `src/app.js`. `pack` is the URL of the pack
  folder. `open` is an optional same-site figure URL to open on start.

**Commands** (run from the repository root, with Quarto's bundled Deno)

```
quarto run tools/figure-editor/scripts/copy-symbol-pack.js [--ref symbols-v0.1.0]
quarto run tools/figure-editor/test/run.js
quarto run tools/figure-editor/scripts/build-sample.js
```

**Files**
- `src/`: ES modules. Everything except `app.js` and `view.js` is DOM-free and tested.
- `test/fixtures/router-fixtures.json`: generated by `gen_router_fixtures.py` from the
  toolbox's own `route()`.
