# Figure editor

Stub (the Scribe writes the documentation). Plan: `proposals/figure-editor.md`.

**Inputs**
- `symbol-pack/`: a pinned copy of `circuit-model/symbols/`. Only
  `scripts/copy-symbol-pack.js` writes it, and `MANIFEST.json` and `VERSION` record the
  source tag and commit. Never edit it by hand.
- Saved figures: circuit-schema `circuit/0.2` JSON (wires carry an optional `level`).
- A private theme (optional): a JSON file shaped like the pack's `theme.json`, of which only
  `roles` is read (`#RRGGBB` values). It is kept in the browser only; it is never saved in a
  figure and never sent anywhere. Files named `*.private-theme.json` are git-ignored.

**Outputs**
- Saved figures (`.json`, canonical: the same figure always gives the same bytes).
- SVG export: real size in cm times the scale option, with no external references, no fonts
  and no text (labels are outlined paths).
- Copy as PNG: 300 dpi at the exported size, on a transparent background.

**API**
- `mount(element, { pack, open })` from `src/app.js`. `pack` is the URL of the pack
  folder. `open` is an optional same-site figure URL to open on start (`?open=` on the page).

**Commands** (run from the repository root, with Quarto's bundled Deno)

```
quarto run tools/figure-editor/scripts/copy-symbol-pack.js [--ref symbols-v0.2.0]
quarto run tools/figure-editor/test/run.js
quarto run tools/figure-editor/scripts/build-sample.js
```

**Files**
- `src/`: ES modules. Only `app.js`, `view.js` and `mathjax.js` touch the browser; the rest is
  DOM-free and tested.
- `test/fixtures/router-fixtures.json`: generated by `gen_router_fixtures.py` from the
  toolbox's own `route()`.
- `test/fixtures/mathjax.json`: real MathJax 4 output for the labels the tests use, made by
  `capture-mathjax.html` (it says how). The editor typesets the same strings live in the browser.

**Labels** need the network the first time: MathJax 4 and its STIX2 font data load from
jsDelivr (the version the site pins), and nothing is drawn with a font.
